# Permission design

`TUITION_VIEW/CREATE/UPDATE/ADJUST/EXEMPT/CANCEL/EXPORT`, `PAYMENT_VIEW/CREATE/CONFIRM/CANCEL/REFUND`, `TUITION_NOTICE_VIEW/ISSUE/PRINT/SEND/CANCEL`, `RECEIPT_VIEW/ISSUE/PRINT/SEND/CANCEL`, `BANK_ACCOUNT_MANAGE`, `BANK_CSV_MAPPING_MANAGE`, `BANK_STATEMENT_IMPORT/VIEW/RECONCILE/CONFIRM/IGNORE/REVERSE`.

Import không mặc định có quyền confirm payment. API bắt buộc kiểm tra quyền, UI chỉ ẩn/disable hỗ trợ.
