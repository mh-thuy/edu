# Payment UI

Payment workspace bắt buộc mã học sinh khi tra cứu, cho phép chọn một hoặc nhiều tuition fee chưa thanh toán của cùng học viên. Mỗi fee hiển thị `finalAmount` read-only; tổng batch là tổng các fee được chọn, không có input thanh toán một phần. Nút chính là “Xác nhận thanh toán toàn bộ”, có dialog cảnh báo, chống double submit và link PDF receipt sau thành công.
